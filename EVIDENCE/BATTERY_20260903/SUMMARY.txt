WHY THIS DIRECTORY EXISTS, and it is not a formality
----------------------------------------------------
Earlier on 2026-09-03 the figures in five files of the dossier were updated to numbers
taken from two places that are NOT the commands printed beside them: a summation of the
per-step counts inside scripts/test.sh (3173 tests, 342 suites) and the ESLint count from
the pre-commit gate (495 files), which lints a different set from `npm run lint`.

Both numbers were real. Neither reproduced with the command it was printed next to.
A reader running `npm test` would have got 3164 and concluded the dossier was padded.

The repair is this directory: every figure now comes from a log written by the exact
command named beside it, and the log is committed. A figure whose command produces a
different number is worse than a stale figure, because a stale one is at least true of
some run.

Two commands, two counts, both correct
--------------------------------------
  npm test          3164 tests   — the reference control plane and the packages
  scripts/test.sh   22 steps     — the whole battery, of which the unit step is one

  npm run lint      473 files    — the source that ships
  pre-commit gate   495 files    — a wider set, including tooling not shipped

They are different questions. The dossier now asks each one with its own command.
