# Industry Module Framework

The core includes the framework; sector modules are built later. A module
contains manifest, publisher, license, intended/excluded use, sector, data
classes, permissions, models, workflows, connectors, policies, UI panels,
validation evidence, update/rollback and support lifecycle.

Lifecycle: discover, verify publisher/signature/license, compatibility and
dependency analysis, sector-policy analysis, quarantine, test, approval,
activation, monitoring, update/disable/rollback/revoke. Customer-specific
modules integrate without exposing ATOM or private NOESAR source.
