# CodeN Ultra Product Specification

CodeN is a native detachable workspace using NOESAR identity, projects, models,
memory, policy, tasks and audit. It shows the verified privacy indicator.

Lifecycle: inspect, understand, propose plan, identify files/dependencies,
request path/command authority, backup, implement, test, review diff, accept or
rollback.

Normal mode provides detailed consent and install/path advice. Owner Bypass is
scoped and timed. Prohibited: implicit root, hidden package installation,
secret extraction, unrelated host access, silent destructive cleanup and
repository instructions treated as privileged authority.
