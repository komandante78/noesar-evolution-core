# Document, Knowledge and Search

Pipeline: ingest, type detection, malware scan, extraction, OCR, structure,
classification, chunking, embeddings, citation mapping, retention and access.
Surfaces: Document Studio, search, Knowledge Graph, LLM Wiki, evidence viewer
and citation history.

The Graph stores typed entities/relations; the Wiki provides human-readable
synthesis with citations. Answers distinguish source content, model inference
and user facts.
