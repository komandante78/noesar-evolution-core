# MEVCM Memory and Contamination Control

Memory layers: session, episodic, semantic, procedural, causal,
organizational and protected Owner memory. Records include provenance, actor,
source class, time, confidence, retention, tenant, legal hold, contamination
state and causal links.

Untrusted content cannot be promoted directly. Promotion requires validation,
policy, conflict detection, contamination canary, optional human approval and
audit. Vector indexes are derived views; authoritative records remain in the
primary store.
