# Implementation Gates

- Gate 0: Master V4 Owner review.
- Gate 1: public/private repository and legal skeleton.
- Gate 2: Security Kernel, identity, brokers and sandbox authority.
- Gate 3: core platform, data, WebUI, documents, workflows and reference reasoning.
- Gate 4: hardware discovery, runtime adapters, models and resource planning.
- Gate 5: private ATOM and Owner providers through frozen contracts.
- Gate 6: Enterprise and Industry Module Framework.
- Gate 7: full acceptance and remediation.
- Gate 8: five final ZIPs from one frozen release.

Every mutating gate requires explicit Owner authorization.
