# V4 Rewrite Changelog

V4 is a complete architecture and governance rewrite based on the V2 functional
baseline, V3.1 architecture and subsequent Owner decisions.

## Added

- Autonomous open core and commercial distribution path
- Public/private repository separation and private ATOM boundary
- Contribution, trademark and grant governance
- Hardware and Runtime Orchestrator with multi-GPU and memory planning
- Dynamic privacy state in Chat and CodeN Ultra
- CodeN Path Authorization Broker and installation-specific Owner Bypass
- Non-bypassable safety invariants
- Technology Radar and signed compatibility/advisory feeds
- Industry Module Framework and trust levels
- Compliance-pack architecture and enterprise evidence package
- Memory-safe core language decision
- PostgreSQL/pgvector default, Qdrant adapter and DuckDB analytics
- TUF, Sigstore, SLSA and CycloneDX supply-chain architecture

## Deprecated

All `WORKING_V0_1_0` and `WORKING_V0_2_0` product archives are non-canonical
experiments and must not be reused as final release foundations.
