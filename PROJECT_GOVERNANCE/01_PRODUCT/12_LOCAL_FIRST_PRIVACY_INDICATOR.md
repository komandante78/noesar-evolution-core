# Local-First Privacy Indicator

States: LOCAL_ONLY_VERIFIED, EXTERNAL_METADATA_ONLY,
EXTERNAL_CONNECTOR_PENDING, EXTERNAL_CONNECTOR_ACTIVE, REMOTE_MODEL_ACTIVE,
POLICY_VIOLATION_BLOCKED and STATUS_UNKNOWN.

External state shows destination, service identity, data categories, purpose,
duration, retention information, consent scope and revoke control. Telemetry is
off by default. User content is never included in license/update metadata.
