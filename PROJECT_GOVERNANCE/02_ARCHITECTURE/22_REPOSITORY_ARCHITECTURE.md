# Repository Architecture

Public organization repositories: core, WebUI, SDK, runtime contracts,
hardware/runtime orchestrator, path authorization, egress broker, sandbox,
secure update client, model descriptors, Industry Module Framework, reference
modules and documentation.

Private repositories: ATOM Evolution, Owner edition, commercial licensing,
signing infrastructure, private Enterprise packs, official medical, surgical,
aerospace, financial and industrial modules, and commercial release builder.

Public repos require license, architecture, build, tests, security policy,
contribution policy, roadmap, issues, changelog and no private dependency.
