# Language and Stack Decisions

Rust is used for authority, privileged resources, policy, brokers, process
supervision, licensing, updates, audit, hardware discovery and recovery.
TypeScript/React provides WebUI but never final authorization. Python is limited
to supervised model/scientific/document workers. Swift provides an optional
macOS Metal/Core ML and secure-storage bridge.

Contracts use OpenAPI, JSON Schema, Protocol Buffers where appropriate,
CloudEvents-compatible envelopes, SPDX and CycloneDX.
