# Measurable Acceptance Matrix

Public governance: build without private repos; reference reasoning without
ATOM; approved licenses; independent funding work packages; active CLA/DCO and
trademark policy.

Security: injection cannot grant authority; traversal/race tests pass; Owner
bypass remains scoped; secrets stay out of model context; egress state matches
traffic; malicious update/model/module rejection; sandbox escape suite;
emergency stop.

Runtime: CPU fallback; real hardware matrix; planner tolerance; supported
multi-GPU; clear rejection of unsupported combinations.

Operations: backup/restore, upgrade/rollback, air-gap, Linux/Windows/macOS/
Unraid and Restricted Continuity. Product: approved UI, no placeholders, V2
traceability and five independently verified final archives.
