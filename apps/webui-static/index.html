THE SAME SESSION, FROM A TERMINAL

CodeN Evolution TUI

The terminal shell attached to the same live session as the workbench.

DECLARED · NOT BUILT

One program, two shells, joined to the same live session — not a second client with its own state. Every capability carries a keyboard form, and the shell shows the same status line as the workbench (UI-054).

It is ranked as a destination and it is not built. It needs the session protocol over a unix socket, which is later work; emulating a terminal here would be a picture of a shell, not a shell.

Declared rather than hidden: the destination is real in the structure, the surface is honestly absent.

GOAL AND CRITERIA · NOT A SEARCH BOX

Research

A report with compared candidates, the evidence behind each one, and what was not verified.

DECLARED · NOT BUILT

The twelfth destination (D-0130), declared rather than hidden inside another page to make the count add up. It takes a goal and criteria, not a string, and returns a report reachable through a temporary link that expires and can be revoked — and that link is not public of itself (UI-080…UI-089). Evidence quality is stated per candidate, because reviews can be bought and an average score is not evidence.

There is deliberately no input on this page. The safety gate (UI-090…UI-096) is a requirement that comes before the surface, not a refinement after it: two doors — on the intent before anything leaves, and on the content that comes back — three outcomes rather than two (proceed · ask · refuse), each refusal naming its category, and no query emitted at all when the intent is refused. It classifies intent and effect; it is not a word list, which any synonym or paraphrase defeats.

It refuses the effect, never the subject: legislation, history, prevention, workplace safety and remediation stay reachable. One category — the exploitation of minors — is not bypassable by any role, the Owner included.

Building the surface first would mean shipping an egress path with no gate on it. The order is the safeguard.

Appearance

Nine themes, and any accent colour you like — with the contrast measured while you choose it, not afterwards.

Theme

—

A theme is a remapping of the interface's colour tokens, not a second stylesheet. Meaning never moves with it: the seven states below keep their glyph and their word in every theme.

Accent colour

Any hue. A hue that does not carry as text is not refused — it stays as the fill, and a readable relative of it is derived by moving away from the background until it reaches 4.5:1. Both figures are shown below.

Stored on this device only. It is a display preference and never leaves the installation.

Reading and motion

Text size

Four steps, and they scale the whole interface — every size in the stylesheet is a multiple of this one, so nothing is left behind at its original size.

Interface zoom
100%

Independent of text size: this moves spacing, controls and type together, the way the browser's own zoom does — without leaving the page.

Motion

Your system preference is honoured on its own. This setting is stronger: it applies even where the system says nothing.

All three are stored on this device only. They are display preferences and never leave the installation.

The seven states

Each carries a glyph and a word as well as a tint, so it survives a theme change, a colour-blind reader, a monochrome print, and high-contrast mode — where the tint is discarded outright.
