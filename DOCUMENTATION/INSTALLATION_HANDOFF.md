# Installation handoff

## Delivery classification

This is the complete NOESAR EVOLUTION V4 implementation delivery, divided into
exactly five final archives. It is not an advance preview, design-only skeleton,
or funding-only release candidate.

## Next operation

Install Package 2 on the owner's isolated Unraid environment, then execute the
included verification procedure. Package 1 is the canonical source authority for
any target-specific correction.

## Remediation rule

When installation exposes an actual defect:

1. capture the exact command, log and environment;
2. make the smallest source correction against Package 1;
3. rerun the relevant test and installation check;
4. preserve rollback material;
5. regenerate manifests and checksums for any changed archive.

Do not conceal installation failures and do not downgrade the delivery to a
mock, skeleton or preview. Treat them as concrete defects in a complete product
implementation and correct them under owner authorization.
