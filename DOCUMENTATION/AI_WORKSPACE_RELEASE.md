# AI Workspace Release

NOESAR Evolution now implements a professional AI workspace around Ask, Create
and Act. The release contains a versioned conversation graph, shared projects,
source-grounded retrieval, scoped transparent memory, editable artifacts,
agents with approval gates, scheduled tasks, data lifecycle controls and
provider-neutral inference.

Local inference remains the default. Users may explicitly enable OpenAI,
Anthropic/Claude, Moonshot/Kimi or custom OpenAI-compatible APIs and may define
routing, fallback and parallel comparison. External use is default-deny and
protected by encrypted credentials, consent scopes, redaction, audit and SSRF
controls.
