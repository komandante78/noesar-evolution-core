
# Hardware accelerator matrix

The architecture and probes cover CPU, NVIDIA CUDA/TensorRT/NCCL, AMD ROCm/HIP, Apple Metal/Core ML, Intel OpenVINO/XPU/NPU, DirectML and ONNX Runtime. The current package contains detection and adapter contracts; it does not claim that every backend has been executed on physical hardware.

Automatic discovery and recommendation are permitted. Automatic driver installation, model download or host mutation require explicit authorization and are outside the default local-first policy.
