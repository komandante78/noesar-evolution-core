
# Release process

1. Freeze source identity and dependency locks.
2. Verify manifests, tests, SBOM and provenance.
3. Build per target in controlled environments.
4. Execute platform acceptance and data-plane tests.
5. Review open findings and claim boundaries.
6. Sign artifacts and update metadata.
7. Publish checksums, release notes and rollback instructions.
8. Preserve evidence and support lifecycle.
