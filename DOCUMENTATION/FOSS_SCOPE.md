
# FOSS scope and private boundary

The funding-compatible public scope is intended to be independently useful, buildable and testable without ATOM Evolution, private signing infrastructure, customer data or a commercial licensing server.

Included public candidates include the reference control plane, public reasoning-provider contract, authority protocol, hardware/runtime orchestration contracts, capability framework, SDKs, schemas, deployment source, verification tooling and documentation.

Excluded private scope includes ATOM Evolution implementation, Owner Unlocked issuance, production commercial-license infrastructure, private signing keys, proprietary datasets and official high-risk Industry Modules. Public interfaces may support those components without depending on them.

Before publication, component-level SPDX headers and repository-specific license files must be finalized through legal review.
