# Licensing Boundary

The intended licensing architecture is:

- Public core: `AGPL-3.0-or-later` OR the NOESAR Commercial License.
- Public SDK, schemas and interoperability contracts: `Apache-2.0`.
- Public documentation: `CC-BY-SA-4.0`.
- ATOM Evolution, Owner Edition, private signing infrastructure and official
  regulated-industry modules: proprietary repositories.

The final verbatim AGPL, commercial, CLA, trademark and documentation license
texts require specialist legal review before public release. SPDX identifiers
are used in source headers to keep boundaries explicit.
