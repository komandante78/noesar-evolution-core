# Code of conduct

This page is short because it is meant to be read, and it is written in this project's own words
rather than adopted from a template.

## What is expected

Talk about the work. Disagree about the work as much as you like — this project's whole method is
that a claim survives being checked, so **saying "that is wrong, and here is the measurement" is
welcome and always will be.** What is asked in return is that you argue with the thing, not with
the person holding it.

Assume the other person is doing their best with what they could see. Most defects in this
repository came from someone not being able to see something, not from carelessness.

## What is not accepted

- Insults, mockery, or comments about a person rather than their work.
- Harassment of any kind, in issues, pull requests, or anywhere else this project reaches.
- Sexual language or imagery, and unwelcome attention of any kind.
- Publishing anyone's private information — an address, a workplace, a real name they did not
  give — without their explicit permission.
- Deliberately wasting people's time: reports invented rather than observed, "evidence" that was
  never run, or an issue opened to make a point rather than to fix something.

## Where it applies

Everywhere this project is: issues, pull requests, discussions, commit messages, and any space
where you are representing NOESAR Evolution.

## Reporting, and what happens

Report it through the private channel named in [`SECURITY.md`](SECURITY.md) — the same one, so
there is one address to keep correct instead of two.

Reports are read by the maintainer. You will get an answer. Depending on what happened, the
outcome may be a private word, an edit or removal of the content, a temporary block, or a
permanent one. Whoever reports something in good faith will not be worse off for having reported
it, and the report will not be repeated to the person it concerns without being asked first.

This project has one maintainer, which means enforcement is one person's judgement. That is a
limitation and it is stated rather than dressed up as a process: if the person you need to report
is the maintainer, say so publicly in an issue, or say it to anyone else involved in the project —
being small is not a reason for a complaint to have nowhere to go.
