# Functional research input — professional AI chat

Date supplied by the product owner: 24 July 2026.

This document records the product input used for the P0 implementation. The implementation phase preserves the owner’s framing: users want a controllable AI work environment rather than a prompt box, organized around **Ask, Create and Act**. The requested P0 areas are conversation control, transparent context, versioned branches, project workspaces, global and semantic search, precise source passages, broad file support, configurable RAG/full-context retrieval, visible memory, local and remote models, installable tools, approval-aware agents, sandbox and secrets protection, editable artifacts, multimodality, data lifecycle controls, explicit reliability and accessible multilingual UX.

The research percentages and third-party findings supplied by the owner are treated as research input. They are not re-certified by the source tree itself. The implementation evidence is tracked independently in `P0_TRACEABILITY.tsv`.
