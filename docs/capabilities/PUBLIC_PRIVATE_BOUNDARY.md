# Public and Private Boundary

Public contracts may describe:

- `AtomProvider`
- `CognitiveExtension`
- `IndustryModule`
- `RuntimeAdapter`
- `HardwareAdapter`
- `PolicyPack`

Public packages must not contain:

- ATOM Evolution implementation;
- private heuristics;
- Owner unlocked entitlement;
- commercial license issuer;
- private signing keys;
- official regulated-sector implementation;
- confidential customer modules.
