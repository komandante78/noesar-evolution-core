# Broker Fail-Closed V0.5.0

The production broker requires:

1. sandbox profile hash;
2. sandbox attestation V3;
3. actor and session bindings;
4. plan and evidence digests;
5. signed execution ticket;
6. unused ticket nonce;
7. OS isolation;
8. integrated production adapter.

V0.5.0 does not integrate the adapter. Native external execution remains denied.
