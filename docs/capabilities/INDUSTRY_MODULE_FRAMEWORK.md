# Industry Module Framework

NOESAR core is general-purpose. Sector-specific behavior is delivered later as
separate modules.

Official high-risk modules require:

- NOESAR or certified-partner publisher;
- precise intended and excluded use;
- jurisdiction scope;
- data classification;
- qualified human oversight;
- safety interlocks when physical impact exists;
- validation and evidence package;
- independent acceptance;
- separate release and maintenance lifecycle.

Customer-private modules are supported for internal workflows. They do not gain
NOESAR certification merely by conforming to the manifest schema.
