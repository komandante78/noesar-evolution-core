# Agents, Workflows and Programmable Documents

Standard flow: objective, generated plan, review/authorize, activate. Advanced
graph editing is optional.

Agents declare identity, purpose, tools, data, network, model, budget, time,
stop conditions, approvals, audit and rollback. Workflows use typed steps,
retries, compensation, idempotency, timeout, cancellation, human approval,
evidence and replay where possible. Document text never becomes system
authority.
