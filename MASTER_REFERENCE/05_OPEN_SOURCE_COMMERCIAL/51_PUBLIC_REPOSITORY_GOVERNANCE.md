# Public Repository Governance

Every public repository provides source, issues, roadmap, build/test docs,
security policy, contribution policy, releases, architecture decisions,
licenses, funding disclosure and reproducible evidence.

Security embargoes may be private, while decisions affecting public contracts
are recorded publicly. Private commercial strategy need not be public. Public
security controls cannot be crippled to sell the commercial edition. Funded
results remain open. Only authorised maintainers sign official releases and use
NOESAR official marks.
