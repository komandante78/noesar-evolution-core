# Five-ZIP Final Delivery Plan

1. Complete Product Source: public core, integration contracts, WebUI, Control
   Plane, security, data, documents, CodeN, reference reasoning, hardware and tests.
2. Runtime and Deployment: OCI, Linux/Windows/macOS/Unraid, air-gap, install,
   repair, update, backup, restore and rollback.
3. Capabilities and SDK: Apps, Tools, Skills, Connectors, module framework,
   SDKs, manifests, signing, quarantine and lifecycle.
4. Security and Acceptance: threat model, red-team, privacy, licensing,
   sandbox, supply chain, platform/accessibility/performance/recovery tests.
5. Final Release and Operations: installable release, complete docs, checksums,
   provenance and handoff.

All five refer to the same frozen release identity and hashes.
