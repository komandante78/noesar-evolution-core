# Observability, Support and Diagnostics

Use OpenTelemetry-compatible traces, metrics and logs. User content is excluded
from diagnostics by default; including prompts, documents, code, memory or
private logs requires explicit Owner consent.

System Doctor validates configuration, storage, database, permissions,
runtime, hardware, models, capabilities, network, license, clock, backup and
updates. Repair plans are previewed and reversible where possible.
