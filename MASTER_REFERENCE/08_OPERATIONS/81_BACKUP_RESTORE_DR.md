# Backup, Restore and Disaster Recovery

Scopes: configuration, user/project, organization, full system and recovery
material. Controls: encryption, hash, manifest, retention, immutable/offline
copy, restore tests, compatibility, safety backup and report.

Restore: verify, compatibility, safety backup, stop mutation, staged restore,
migration, health, integrity and user acceptance. Enterprise defines RTO/RPO,
replication, failure domains and exercises.
