# Public and Private Component Boundary

Public mandatory components include WebUI, Control Plane, Security Kernel,
path/egress brokers, sandbox, identity, policy, audit, update verifier, hardware
discovery, runtime contracts, model descriptors, reference reasoning, document
and workflow foundations, module framework and SDK.

Private components include ATOM implementation, Owner entitlement issuer,
private keys, commercial license service, proprietary Enterprise packs and
official regulated modules. Public work fails acceptance if it cannot
independently demonstrate its primary purpose.
